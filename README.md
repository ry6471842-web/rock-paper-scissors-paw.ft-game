🐾 Paw♡Paper♡Scissors

A cozy pixel-art Rock Paper Scissors game built with HTML, CSS, and JavaScript. All artwork is hand-drawn by me, and the project focuses on creating a cute, interactive experience rather than just implementing the game logic.

This repository is a work in progress and will continue to evolve as I learn new web development concepts. I'm using this project to practice front-end development, JavaScript, animations, and UI/UX design.

///Current Features//



Playable Rock Paper Scissors game
Custom hand-drawn pixel art
Animated sleeping cat on the start screen
Cozy pastel pixel aesthetic
Score tracking
Separate start and game screens


//Planned Features//


Animated paw buttons
Awake cat companion with idle animations
Heart and particle effects
Sound effects and background music
Improved transitions
Win/Lose animations
Better responsive layout
Purpose

This project serves as both a learning journey and a portfolio piece. As I learn new techniques, I'll continue improving the code, artwork, animations, and overall user experience.
